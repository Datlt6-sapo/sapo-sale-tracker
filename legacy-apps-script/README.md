# Đã ngừng dùng (deprecated)

Đây là bản cũ chạy trên Google Apps Script. Đã chuyển hẳn sang Firebase (xem thư mục
`public/` ở gốc repo) vì Apps Script triển khai bất tiện: deploy phức tạp (phải tạo
version mới mỗi lần sửa), load chậm (phải qua lớp iframe sandbox riêng của Google),
lỗi khó debug (console/log tách rời, không rõ nguyên nhân thật khi gặp sự cố).

Giữ lại thư mục này chỉ để tham khảo lịch sử, không nên deploy lại.
